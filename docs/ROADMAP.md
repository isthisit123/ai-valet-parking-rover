## 최종 앱과 제어 기준

- 최종 Import 파일은 `apps/qrover_encoder/q_rover_encoder_receiver.zip`이며 소스는 같은 이름의 폴더에 있습니다. PC는 `web_drive.py --encoder-drive`를 사용하고 실제 구동에 `--drive`를 추가합니다.
- 실물 환경은 웹캠 1번, 핫스팟 연결, 실측 윤거 15cm입니다. 보드 IP는 실행 시 입력합니다.
- 엔코더는 D2/D7, 모터는 D5/D3·D6/D9, 왼쪽 극성 1·오른쪽 -1, 전진·회전 PWM 150입니다. 다른 하드웨어의 보정값으로 일반화하지 않습니다.
- 로버는 높이 보정 마커 중심 한 점으로 취급합니다. 방향은 조향에 사용하고 도착에는 사용하지 않습니다. 최종 도착은 중심 간 기본 2cm이며 차체 전체가 칸 안에 있는지 검사하지 않습니다.
- 최종 Export의 ToF는 비활성화 상태입니다. 장애물 자동 정지와 차체·회전 궤적 충돌 회피는 제공하지 않습니다.
- 최종 소스의 빈 줄 공백 한 곳만 정리했고 Import ZIP에도 동기화했습니다. 제어 코드는 보존했으며 원본 Export와 이전 수신 앱은 Git 제외 `backups/`에 보관했습니다.
